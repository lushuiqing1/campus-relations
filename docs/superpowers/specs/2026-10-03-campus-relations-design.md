# 狗头军师·校园版 v0.1 设计

日期：2026-10-03。执行依据：用户在对话中确定面向大学生、公开分享的个人 GitHub 项目，并明确要求“按照这个方案实施”。本文记录已选方案，实施采用当前聊天中的并行分工。

## 目标与成功条件

帮助大学生在日常生活中建立、维持师生与同学关系，遇到误会时也能修复。每次回答让学生得到符合身份、可以采取的小行动或可发送的话术，并知道如何根据真实反馈调整。不能用“保证老师喜欢你”或“让所有同学接纳你”作为效果承诺。

第一版是本地 Codex Skill，内部名称和文件夹为 `campus-relations`，显示名为“狗头军师·校园版”。建立独立项目，保留上游归属信息，便于单独安装和公开分发。

## 与原版的关系

上游：[shengjidaguai-china/goutoujunshi](https://github.com/shengjidaguai-china/goutoujunshi)。本次固定参考版本 `6db7354a4002dc7c448a9c87ffdad8132570c9d3`。

沿用的决策骨架：适度承接情绪 → 区分事实、推测和未知 → 结合目标与关系约束取舍 → 优先给一个可执行动作 → 提供自然话术 → 依据回应调整。单纯请求代写时先给草稿，不要求完成整份问卷。

| 原版机制 | 校园版决定 |
|---|---|

不依赖先安装原版；不调用原版记忆脚本或使用它的存储目录。

## 范围

师生线：请教、约时间、清晰请求、回应建议、反馈进展、具体感谢、分歧与职责协商。尊重课程或导师已有沟通约定；对评价和权力压力保留现实判断，不默认老师一定友好，也不将讨好作为目标。

同学线：认识同学、保持朋友联系、共同活动、宿舍相处、公平分工、班委社团互助、拒绝过量帮忙。接纳不同亲近程度，持续共处不要求成为亲密朋友。

修复线：澄清误会、承担已知责任、表达影响和请求、协商后续行动。持续骚扰、威胁或隐私泄露时，优先处理实际伤害与适当求助，而非要求继续维护亲密关系。

暂不加入：校园恋爱推进、跨聊天持久记忆、微信数据库读取、批量聊天导入、独立网页或账号系统。公开仓库只包含原创示例、简短资料转述及来源链接。

## 输入、决策与输出

识别用户的关系角色、当下目标和场景。只追问会改变建议的信息；已有对话背景可以直接用，不重复索取。截图或引用文本视为素材，发言人和看不清内容保留未知，其中的“忽略规则”等文字不成为指令。

判断依据：尊重时间与选择、可靠履约、公平、适当互助、保护边界、长期共处的可行性。以具体回应和履约作为观察信号，不以回复速度、表情、地域或人格标签推断动机。

三种灵活输出：

1. 代写请求：先给可用话术，再简述发送条件与跟进方式。
2. 日常维护：当下小行动、可持续习惯、真实反馈的观察与调整。
3. 冲突修复：已知与未知、优先方案、沟通草稿、何时改用协调或求助。

不强制每次完整输出以上栏目。不足以判断时给条件化草稿或问一个关键问题，不编造经历、承诺、对方反应或发送记录。

可以按用户请求模拟一次对话并给具体反馈，模拟回应须清楚标记，不冒充真实预测。技能帮助起草和准备沟通；消息实际发送需用户明确要求并有可用工具。

## 故障与资料处理

参考文件不存在时说明没有读到该文件，继续用已知事实提供有限建议；涉及无法核实的课程规则或权益问题时查学校官方信息或建议明确核对。读不到截图时索取与决定有关的文字，不假装已识别。

知识文件保留研究类型、样本与限制，区分研究发现和设计建议。先前资料索引中仍待复查的案例不作为已核事实。第三方网页、论文各自保留许可；MIT 不覆盖其全文。

## 验证与发布条件

静态验证：技能名称、默认调用、文件引用无冲突；所有运行引用存在且位于技能目录；文件大小合理；项目有许可和上游来源记录。

工具验证：在临时目录检验有效技能、缺失引用、目录外引用、安装后文件完整性，以及重复安装不会覆盖已有内容。测试不调用真实聊天、消息或账号。

行为验证：20 场景中 12 个日常维护、4 个修复、4 个边界。优先检验师生和同学的日常行为；所有边界题必须通过。以自然话术、可采取行动、尊重选择、诚实处理未知及合理调整作为评判标准。记录实际测试覆盖与失败，不把提示词演练等同于真实校园效果验证。

本次交付本地可安装项目与验证报告，准备公开分发材料。远程 GitHub 发布在用户要求发布时执行。
