# S01

原输入：老师说报告要联系实际，但我不确定是分析一个真实案例还是写自己的经历。我第一次给这位老师发邮件，想问清楚，怎么写？

回答：

主题：【课程名】报告“联系实际”要求请教

【老师姓氏】老师您好！我是您【课程名／班级】的学生【姓名】。想请教一下报告要求中“联系实际”的含义：是分析一个真实案例，还是结合自己的经历来讨论？这两种方式是否都可以，或者您更希望采用其中一种？谢谢老师。

【姓名】

第一次联系，交代课程和身份就够了，问题也可以这样直接列清楚。发送前看一眼作业说明有没有现成解释；若课程指定了提问渠道，沿用那个渠道。收到回复后简单说“谢谢老师，我明白了”，再按要求准备即可。

# S02

原输入：我上课听不懂一个公式，自己查过还是卡在第二步。老师有答疑时间，可我怕问题太简单，浪费他时间。

回答：

你已经查过，也知道卡在第二步，这就能形成一个具体的答疑问题，不必先证明它“够难”。把公式和自己的推导带过去，圈出那一步，可以说：

“老师，我想请教这个公式从第一步到第二步的变化。我查过【实际查过的资料】，但还没理解这里为什么能这样变形。您能帮我指出我漏了哪个条件或知识点吗？”

按公布的答疑安排参加；如果需要预约，就先预约。老师若建议你补看某个基础概念，照着再试一次，仍卡住再说明新的卡点。这样问题范围清楚，也方便老师判断从哪里解释。

# S03

原输入：我是学习委员，老师临时让我统计几份材料，今晚还要复习。我愿意帮忙，但这周真的做不完，怎么说比较合适？

回答：

可以尽早说：

“老师，您刚交代的材料统计我愿意帮忙，但这周的复习安排和这项工作有冲突，全部统计我这周确实做不完。想和您确认一下最晚需要的时间：如果必须这周完成，能否请其他同学分担，或者先确定最急的一部分？”

先把真实的时间冲突和做不完的范围说清，不必为了显得配合答应全部。若你确实还有余量，再补“我能在【真实时间】前完成【具体部分】”；没有就不用加。沟通后确认谁接哪部分、何时交，避免“分担一下”最后仍变成你负责全部。

# S04

原输入：我昨天问老师能不能帮忙看一下选题，他已读但没回。我是不是给他留下坏印象了？下周才要交选题。

回答：

昨天已读但没回，只能说明目前没有收到答复，还不能据此判断老师对你印象不好。可能是当时没空，也可能需要之后再看，具体原因现在不知道。

选题下周才交，你可以先继续整理题目、研究范围和最想确认的一点。结合答疑安排，给自己留出修改时间后，再在原消息里跟进一次：

“老师您好，想跟进一下选题请教。提交截止是【具体日期】，我主要想确认【一个具体问题】。您如果方便看一下，我会据此调整；如果答疑时讨论更合适，我也可以按答疑安排过去。”

不用为一次未回复反复解释或道歉。

# S05

原输入：隔壁座位的同学跟我选了一样的课，我们聊过两句。我想以后一起去上课，但又怕突然邀请很尴尬。

回答：

可以先约下一次上课，范围小一点，说起来更自然：

“你下次这节课准备什么时候过去？要是时间差不多，我们可以一起去。你有别的安排也没事。”

你们已经聊过，又有共同课程，这就是一个现成的开口机会，不用先铺垫成“我想和你交朋友”。对方愿意，就确认集合时间和地方；对方另有安排，就正常回一句“好，那课上见”。之后碰见仍可以打招呼，不必用这一次邀请判断关系。同行几次都舒服，再顺势问以后是否一起走，让习惯逐渐形成。

# S06

原输入：朋友又问我要整份作业，想直接照着交。我可以讲思路，但不想把答案都给他，怕他说我不够朋友。

回答：

可以直接回：

“整份答案我就不发了，我不想让自己的作业被直接照着交。你哪一步不会可以告诉我，我能跟你讲思路，你再自己写。”

你愿意帮到什么程度，这句话已经说清楚了，不必为了证明够朋友交出全部答案。若他回“以前都给，怎么现在不行”，可以说：“之前给过，但以后我想按这个方式帮你。”若他说你不够朋友，也不用争论谁更讲义气，简短重申：“我愿意讲思路，整份答案不提供。”看他能否接受这个范围，再决定继续讲题；你也可以按自己的时间安排帮忙。

# S07

原输入：我们四个人刚组队做展示，还没开始。我不想当领导，但想先把分工说清楚，免得最后都赶在一起。

回答：

可以在群里这样开口：

“咱们先一起把展示要做的几块和分工定一下吧，免得最后都挤在截止前。先看课程要求，再各自说想负责哪块、什么时候能交。我也接一块。每项记一下负责人、要交的内容和放在哪里；还得有人负责合并，合并后留时间一起检查、试讲。”

这是发起一次共同讨论，不等于你要包办管理。大家选完任务，再一起确认第一次交稿和合并时间，用实际截止日期往前安排。遇到任务重叠或没人接的部分，当场商量调整；时间排不开也提前说，别默认由你兜底。

# S08

原输入：我最近早上有课，室友喜欢晚上语音聊天。他还不知道我这学期的安排，我想先跟他商量一下。

回答：

挑你们都没在通话、赶事的时候说：

“我这学期早上有课，晚上想在【你实际打算睡觉的时间】左右睡。想跟你商量一下，这个时间之后语音聊天能不能压低声音？如果还要聊比较久，能不能去方便通话的地方？你一般什么时候聊天，我们看看怎么安排都方便。”

他还不知道你的课表，先告知需要、一起商量就可以，不用从“你总影响我”说起。把约定落到具体时间和做法，耳机能减少外放，但说话声也需要考虑。双方同意后先试几晚，再看看是否需要调整。

# S09

原输入：室友经常借我的鞋。我以前借过，现在不太舒服，想以后不借了，但怕他说我突然变小气。

回答：

可以在下次借之前主动说：

“跟你说一下，我以后鞋就不外借了。之前借过，但最近我发现自己还是不太习惯，所以想把这个习惯改一下。”

不需要编鞋容易坏、家里不让借之类的理由。以前同意过，不等于以后必须继续同意。若他问“怎么突然这么小气”，可以平静回：“我知道跟以前不一样，但我现在确实不想借鞋了，希望你理解。”说清一次后，下一次再问就简短重申，不用每次重新辩解。你们其他事情仍正常相处；这条边界是否被尊重，比他当场是否高兴更值得观察。

# S10

原输入：好朋友约我周末出去，我这次想自己休息，不是跟他有矛盾。怎么说不会把事情搞得很严重？

回答：

可以轻松一点回：

“这周末我想自己待着休息一下，这次就先不出去啦。谢谢你叫我，等我有精神了再约。”

如果你确实愿意以后再约，保留最后一句；暂时没有安排，也可以只说到“谢谢你叫我”。不用主动写一大段解释，把一次休息变成关系说明。若他追问是不是有事，再补：“没跟你闹别扭，就是这次想自己休息。”他有点失落也可以理解，但你不用因此改口答应。说完照常联系、分享日常即可，不必额外安排一场活动来证明友情。
